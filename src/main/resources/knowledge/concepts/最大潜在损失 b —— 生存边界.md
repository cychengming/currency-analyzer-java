# 最大潜在损失 b —— 生存边界

*《重回凯利公式：最大潜在损失b篇》核心提炼*

## 核心观点

b 不是止损距离，而是**结构失效时，暴露在坠落维度中的资本比例**。

## 止损的致命误区

大多数人以为设置止损（2%、5%、10%）就能控制风险。但这是建立在**价格连续**的假设上。

现实市场在结构断裂时从来不是连续的：

```
你以为：-5% → -6% → -7% （连续）
现实中：-5% → -20%（跳空，中间没有成交）
```

不是你没执行止损，而是根本没有你可以执行止损的价格。

## b 的真实定义

> b 是你参与系统断裂的深度。这是系统同步崩塌中的位置变量。

## b 由什么决定？（几乎都不在个人控制范围内）

| 决定因素 | 个人能否控制 |
|---------|------------|
| 市场同质化程度 | ❌ |
| 杠杆层级 | ❌（但可选择不用杠杆） |
| 流动性弹性 | ❌ |
| 强制平仓机制 | ❌ |

## 趋势各阶段的 b

| 阶段 | b 的状态 | 含义 |
|------|---------|------|
| 趋势早期 | 小 | 探索成本，结构干净 |
| 趋势中段 | 可控 | 有多空博弈，流动性连续 |
| 趋势末端 | 趋近无限 | 自激正反馈，一致性踩踏 |
| 奇点区 | 无法估计 | 凯利直接失效 |

## 三个变量的终极关系

- **p** → 能不能下注（门槛）
- **R** → 值不值得下注（效率）
- **b** → 能否活下来（**生存**）

> 真正的风险不是波动，是一致性 + 杠杆 + 流动性塌缩。
