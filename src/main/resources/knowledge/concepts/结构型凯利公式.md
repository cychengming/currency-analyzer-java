# 结构型凯利公式

> 来源：[[投资交易的数学哲学]] 第三章

## 核心公式

对原始凯利公式做关键变量转换：令 **R = a / b**（即风险回报率，每单位亏损所对应的潜在盈利）

$$f* = [p(R + 1) - 1] / (R · b)$$

| 变量 | 含义 |
|---|---|
| f* | 最优下注比例（占总资金的比例） |
| p | 胜率：你认为成功的概率是多少 |
| R | 风险回报率：这笔交易的收益与风险比率 |
| b | 最大亏损：你能承受的最大亏损比例 |

## 公式本质

> "你的信心 × 结构强度 ÷ 损失成本 = 你的最优下注比例。"

这个公式的最大价值，在于它把"仓位决策"从情绪判断，转化为一种结构判断：

**不是"我感觉这笔交易很好"，而是"这笔交易的结构，是否值得我下注"。**

## 三个变量拆解

### 1. 胜率 p：信念强度

- 这是你对自己判断能力的信心指标
- 不能完美预测，但可以通过历史经验、策略统计、系统回测形成估算
- **关键在于：谨慎低估胜率比盲目高估更安全，宁低勿高**

### 2. 风险回报率 R：结构质量

- R 越高，意味着这个结构越"凯利友好"
- **高风险回报率可以容忍低胜率**：比如 R=5 时，只需 p > 0.167（胜率17%）就有正凯利值，值得下注
- 很多交易策略（如趋势跟随、期权押注）本质上就是高 R 结构

### 3. 最大亏损 b：风险成本

- 决定了仓位放大倍数的分母，b 越小，f 越大
- 实战中，b 不一定等于止损位，而应是极端情况下可能遭受的最大损失
- **越保守越稳健越安全**，因为止损可能失败，关键时刻市场流动性枯竭，无法止损

## 应用场景示例

假设一笔交易：
- 胜率估算为 30%（p = 0.3）
- 风险回报比为 5:1（R = 5）
- 最大亏损控制在 2%（b = 0.02）

代入公式：
$$f* = [0.3 × (5 + 1) - 1] / (5 × 0.02) = (1.8 - 1) / 0.1 = 0.8 / 0.1 = 8$$

✅ 理论最优下注为 **8 倍（800%）**

由于凯利值波动大，实际操作中你可能只采用：
- 半凯利：f = 4（400%）
- 四分之一凯利：f = 2（200%）

**结论：结构优秀的交易，即使胜率不高，也值得你认真下注。**

## 反面案例

相反，那些"胜率很高，但风险回报率不佳，潜在损失很大"的交易，可能凯利值反而为负，应当直接放弃。

因为所谓"胜率"，只不过是你的估计，是一种幻象。风险回报率不佳，潜在重大损失，也无法用高额回报补偿。一旦胜率失算，或者高胜率遇到"黑天鹅"，重大损失无法弥补，复利受损，得不偿失。

## 真正用法

**结构型凯利公式的真正用法，不是为了告诉你"该下注多少"，而是用来问你：""这笔交易的结构，值不值得我下注？""**
