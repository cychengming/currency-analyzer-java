# MC 谈投资 — 核心投资哲学

作者：Michael Chen（MC），博客：michael-chen.blog.caixin.cn

## 核心思想

### 投资连续性
- 投资是连续过程，"十年树木"，不以为年度划分而人为分断
- 投资者只需时时浇花灌水，除虫避害，坐等其成
- 春华秋实，四季有时——物极必反，盛极必衰，没有树木能长到天上去

### 持股心法
- 买入时仔细盘算，持有时安坐如山
- 关注股权数目是否增加、盈利是否增长、分红是否增加
- 监察公司经营之道，而非每日股价波动
- "做好功课，在零风险之下，重锤出击，才是致富之道"（林森池）

### 反对盲目操作
- 反对"盲目买入，死抱不放"
- 反对"好公司不问价买入而终身持有"
- 投资之道，重在通达而不墨守

### 风险管理
- 风险管理的核心：是对企业认知多少
- 以素质来降低风险，而非以分散投资来降低风险
- 以股息率为准绳厘定买入价，克服熊市恐惧心理
- 最坏打算是长线投资，坐收派息，只要打赢美国30年长债便可
