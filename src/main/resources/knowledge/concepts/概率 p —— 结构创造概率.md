# 概率 p —— 结构创造概率

*《重回凯利公式：概率篇》核心提炼*

## 核心观点

大多数人理解的概率（胜率）是错觉。市场中的概率不是先验存在的，而是由**结构创造**的。

## 教科书概率的两个前提

1. 样本空间有限、权重相等
2. 生成机制稳定

市场不满足任何一条——市场是**演化系统**，不是抽样系统。

## 概率的真实来源

```
混沌 → 趋势形成（正反馈） → 方向性吸引域 → p 被创造
```

p 不是观察结果，而是**结构属性**。它衡量的是：
- 结构偏向度
- 吸引域大小
- 对称性的破缺程度

## 概率的生命周期

| 阶段 | p 的状态 | 说明 |
|------|---------|------|
| 混沌 | 不存在 | 扩散场，无方向结构 |
| 趋势形成 | 出现 | 正反馈创造吸引域 |
| 趋势末端 | → 1（幻觉） | 结构塌缩，集体看多 |
| 奇点附近 | 失效 | 吸引域解体，退为混沌 |
| 结构重建 | 重生 | 新方向性吸引域形成 |

## 反直觉结论

**胜率最高的时候，最不该下注。** 趋势末端 p→1，但 R→0、b→∞，代入凯利公式最优仓位仍然是 0。
