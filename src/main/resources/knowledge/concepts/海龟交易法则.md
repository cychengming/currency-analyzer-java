# 海龟交易法则

> 来源：柯蒂斯·费思（Curtis Faith）著，中信出版社。此页是交易规则笔记，书的全文不在仓库里。

## 海龟实验背景

1983年，理查德·丹尼斯（Richard Dennis）与威廉·埃克哈特（William Eckhardt）争论一个问题：**伟大的交易员是天生的还是后天培养的？**

为了验证，丹尼斯招募了13个完全没有交易经验的人，教授他们一套交易系统，每人给100万美元让他们去交易。这些学员被称为"**海龟**"。

结果：**4年中，海龟们取得了年均复利80%的收益**。丹尼斯证明了用一套简单的系统和严格的纪律，普通人也能成为优秀的交易员。

柯蒂斯·费思——本书作者，海龟计划期间管理的账户最大，**为丹尼斯赚了3100多万美元**。他只有19岁，是海龟中最年轻的一个。

## 四大核心原则

海龟培训课的所有内容可以归结为4个要点：

| # | 原则 | 含义 |
|:-:|:----|:-----|
| 1 | **掌握优势** | 找到一个期望值为正的交易策略，长期能创造正的回报 |
| 2 | **管理风险** | 控制风险，守住阵地，否则等不到策略成果的那一天 |
| 3 | **坚定不移** | 唯有坚定不移地执行策略，才能真正获得系统的正期望值 |
| 4 | **简单明了** | 海龟方法的精髓是简单，而不是复杂 |

## 海龟交易系统详解

### N（真实波动幅度均值 / ATR）

海龟使用**N**（即ATR）来衡量市场波动性，并据此决定头寸规模：

$$N = \frac{19 \times 前一日N + 当日真实波动幅度}{20}$$

真实波动幅度 = max(当日最高-当日最低, 当日最高-前日收盘, 前日收盘-当日最低)

### 头寸规模计算

$$单位 = \frac{账户净值的1\%}{N}$$

- 每份合约的头寸规模根据N动态调整
- 目的是让**所有市场的绝对波动幅度大致相等**
- 根据波动性调整交易量，是海龟的核心创新之一

### 入场规则：两个突破系统

**系统1（中期，20日突破）：**
- 价格突破过去20日最高点 → 做多
- 价格跌破过去20日最低点 → 做空

**系统2（长期，60日突破）：**
- 价格突破过去60日最高点 → 做多
- 价格跌破过去60日最低点 → 做空

> 方法称为**唐奇安通道法**（Donchian Channels），由理查德·唐奇安普及。

### 加仓规则：金字塔式

- 每上涨0.5N加仓一个单位
- 最多持有4个单位
- 逐步增加，控制风险

### 止损规则

- 所有头寸的损失不得超过**2N**（即账户净值的2%）
- 止损位设在买入价下方2N处
- 这是**破产风险控制**的核心

### 退出规则

- 系统1：10日反向突破退出
- 系统2：20日反向突破退出

## 行为金融学与心理偏差

海龟成功的关键不是系统本身，而是**克服人类固有的心理偏差**：

### 主要认知偏差

| 偏差 | 描述 | 对交易的影响 |
|:----|:-----|:------------|
| **损失厌恶** | 损失的心理影响比赢利大一倍 | 不愿止损，死扛导致爆仓 |
| **沉淀成本效应** | 考虑已花掉的钱而非未来 | 继续持有错误头寸 |
| **处置效应** | 卖涨留跌 | 截断利润，让亏损奔跑 |
| **结果偏好** | 以结果而非决策质量判断对错 | 连续亏损时放弃正确系统 |
| **近期偏好** | 更重视近期数据 | 过度优化，追逐短期热点 |

### 海龟的应对

> "损失只是做生意的成本，并不代表着一次错误交易或一个坏决策。"

- 以长远眼光看待交易
- 相信期望值为正的系统长期必能成功
- 损失期通常是赢利期的前兆
- 在困境之中坚守法则，是海龟成功的核心

## 破产风险与资金管理

破产风险是海龟培训的第一课：

> 破产风险会随着赌注的增加而不成比例地迅速增大。如果你把每次的赌金翻一番，破产风险一般不止翻一番——视系统特性的不同，风险有可能翻上两番、三番甚至四番。

### 海龟资金管理法则

- 把头寸分成**小块**（头寸单位）
- 基于波动性（N）动态调整头寸规模
- 任意单笔交易风险控制在**账户净值的2%以内**
- 分散投资于多个市场

## 四种市场状态

| 状态 | 描述 | 适合策略 |
|:----|:-----|:---------|
| 稳定平静 | 价格在小范围内波动 | 不太适合趋势跟踪 |
| 稳定波动 | 有大的日间变化，无月际变化 | 波段交易 |
| **平静的趋势** | 缓慢运动，无剧烈回调 | **趋势跟踪最佳** ✅ |
| 波动的趋势 | 大的变化，剧烈短期逆转 | 趋势跟踪较难 |

趋势跟踪者喜欢**平静的趋势**。在这样的市场中，他们既可以赚钱，又不必忍受剧烈的反向变化。

## 趋势跟踪的三个痛点

1. **大趋势很少出现** — 失败概率远大于成功概率（65-70%的交易可能是亏损的）
2. **衰落期不可避免** — 趋势结束后的回撤可能持续几个月，账户可能从高点下跌30%
3. **需要较大资金量** — 入场价与止损价差距大，资金太少容易破产

## 与知识库的关联

### 与[[凯利公式]]的数学同源

海龟的资金管理本质上是凯利公式的实践：
- 2%风险规则 ≈ 保守凯利
- 基于波动率的动态调整
- 强调正期望值系统

### 与[[复杂系统中的生存哲学]]的完美对应

| 海龟法则 | 生存哲学 |
|:---------|:---------|
| 掌握优势（正期望值） | 识别p（结构是否存在） |
| 让利润奔跑 | 利用R（未来空间） |
| 严格止损（2%） | 控制b（坠落维度） |
| 趋势跟踪 | 在趋势中段重仓 |
| 突破入场+反向突破退出 | 趋势三段论（早期→中段→末端） |

### 与[[苏黎世投机定律]]的呼应

两者都强调**系统化交易、风险控制和心理纪律**，但海龟更具体、更具操作性。

### 与[[克罗的趋势跟踪交易哲学]]的同源

两者都是趋势跟踪，海龟更量化、规则化：
- 克罗：顺大势逆小势、50%回调加仓
- 海龟：突破入场、0.5N加仓、10/20日退出

### 与[[霍华德·马克斯投资哲学]]的共鸣

- 都不依赖预测
- 都强调风险控制优先
- 都重视心理因素
