# 估值框架 v1 —— 五维快筛

> 与 [[复杂系统投资框架总图]] 平行。Kelly 框架回答「什么时候买」，估值框架回答「买什么」。

---

## 一、定位

```
估值框架 → 标的池过滤器（这家公司值不值得长期持有？）
    │
    ▼
Kelly 框架 → 时机选择器（现在是好的入场点吗？）
    │
    ▼
仓位管理 → f* 计算 + 风控约束
```

两层串行。先过估值关——不过关的标的不进 Kelly 扫描池。

---

## 二、五维评分

### 维度一：增速——这公司还在长吗？

| 指标 | 怎么算 |
|:---|:---|
| 营收增速 | 近 3 年营收 CAGR |
| 利润增速 | 近 3 年归母净利润 CAGR |

> 用 CAGR 不是单年增速——过滤掉一次性爆发。

```
评分：
  ≥ 25%  → ⭐⭐⭐⭐⭐  高速成长
  15-25% → ⭐⭐⭐⭐    稳健成长
  8-15%  → ⭐⭐⭐      温和成长
  0-8%   → ⭐⭐        停滞
  < 0%   → ⭐          衰退
```

> **利润增速优先于营收增速。** 营收涨 30% 但利润涨 5% = 增收不增利 = 竞争恶化。综合评分取二者中较低的那个。

---

### 维度二：性价比——增长值不值这个价？

| 指标 | 怎么算 |
|:---|:---|
| PEG | PE（滚动 12 个月）÷ 利润增速（%） |

```
PEG 评分：
  < 1.0  → ⭐⭐⭐⭐⭐  低估
  1.0-1.5 → ⭐⭐⭐⭐   合理偏低
  1.5-2.5 → ⭐⭐⭐     合理
  2.5-4.0 → ⭐⭐       偏贵
  > 4.0  → ⭐          昂贵
```

| 互补指标 | 怎么算 | 问什么 |
|:---|:---|:---|
| FCF 收益率 | 自由现金流 ÷ 市值 | 「如果买了它，靠现金流多久能回本？」 |

```
FCF 收益率评分：
  ≥ 10%  → ⭐⭐⭐⭐⭐  极度安全——每年拿回 10% 以上的现金
  5-10%  → ⭐⭐⭐⭐   有安全垫
  3-5%   → ⭐⭐⭐     一般
  1-3%   → ⭐⭐       安全垫薄
  < 1%   → ⭐          没有安全垫

PEG 和 FCF 收益率互补：
  → PEG 看「成长值不值这个价」（适合成长股）
  → FCF 收益率看「资产本身能产生多少现金」（适合成熟股/基础设施）
  → PEG 好但 FCF 收益率低 = 成长在买单，一停就崩
  → FCF 收益率高但 PEG 差 = 增速不够，但资产本身在印钱
  → 性价比取二者中较优的那个——不要因为 PEG 差而错过印钞机
```

> **来源：Chris Hohn（TCI）——「伟大的公司不一定是伟大的投资。你需要看自由现金流收益率来判断什么时候是好时机。」他在 Aena 机场的投资就是 15% FCF 收益率时进场。**

> **增速用利润增速，不是营收增速。** PEG 不适用于利润为负的公司——负利润直接 ⭐。

> **A 股特注：** A 股整体估值偏高。PEG 1.5-2.5 在 A 股可以视为「合理」。不要用美股的 PEG < 1 标准苛求 A 股。

---

### 维度三：生意质量——这公司赚钱能力强吗？

| 指标 | 怎么算 | 为什么重要 |
|:---|:---|:---|
| ROE | 归母净利润 ÷ 归母净资产 | 每一块钱股东的钱能赚多少 |
| 毛利率 | (营收 - 营业成本) ÷ 营收 | 定价权的温度计 |

```
ROE 评分：
  ≥ 20%  → ⭐⭐⭐⭐⭐  优质生意
  15-20% → ⭐⭐⭐⭐    好生意
  10-15% → ⭐⭐⭐      普通生意
  5-10%  → ⭐⭐        差生意
  < 5%   → ⭐          不赚钱

毛利率辅助：
  毛利率在上升 → ROE 评分 + 半颗星
  毛利率在下降（连续 3 年）→ ROE 评分 - 半颗星
```

> **ROE 要稳定。** 一年 25% 但前两年都是 8% = 不可持续。看 3 年趋势。

---

### 维度四：利润真实性——赚的是真钱吗？

| 指标 | 怎么算 |
|:---|:---|
| 现金流质量 | 经营活动现金流净额 ÷ 净利润 |

```
评分：
  > 1.0  → ⭐⭐⭐⭐⭐  利润含金量高
  0.8-1.0 → ⭐⭐⭐⭐   利润基本真实
  0.5-0.8 → ⭐⭐⭐     需要关注（部分利润是应收账款）
  0.3-0.5 → ⭐⭐       利润质量差
  < 0.3  → ⭐          利润可能造假
```

> **连续 3 年现金流质量 < 0.5 = 直接跳过。** 不管增速多高——没看到现金的利润不算利润。

---

### 维度五：财务安全性——能活过冬天吗？

| 指标 | 怎么算 |
|:---|:---|
| 资产负债率 | 总负债 ÷ 总资产 |
| 有息负债率 | 有息负债 ÷ 总资产（更严格） |

```
评分（用资产负债率）：
  < 30%  → ⭐⭐⭐⭐⭐  极其稳健
  30-50% → ⭐⭐⭐⭐    健康
  50-65% → ⭐⭐⭐      中等（需要看行业）
  > 65%  → ⭐⭐        偏高
  > 80%  → ⭐          危险

行业修正：
  金融/地产：天然高杠杆，用更高阈值
  制造业：50% 是警戒线
  轻资产/消费：30% 是警戒线
```

> **高杠杆 + 低 ROE = 死局。** 借钱不赚钱是纯粹的资本毁灭。

## 三、综合评级

```
总分 = 五个维度的平均星数

≥ 4.0 → ⭐⭐⭐⭐⭐  卓越 — 值得长期持有，积极关注 Kelly 买点
3.0-4.0 → ⭐⭐⭐⭐  优质 — 可以持有，等 Kelly 信号进场
2.0-3.0 → ⭐⭐⭐    一般 — 不排斥但也不主动。Kelly 信号来了可以小仓位
< 2.0 → ⭐⭐        差 — 不进入标的池
```

**一票否决（不论总分）：**

| 条件 | 理由 |
|:---|:---|
| 连续 3 年现金流质量 < 0.5 | 利润可能是假的 |
| 利润增速 < 0 且 PEG > 5 | 衰退 + 贵 = 双杀 |
| 资产负债率 > 80% 且 ROE < 8% | 高杠杆不赚钱 |
| 毛利率连续 3 年下降 > 5 个百分点 | 竞争地位在恶化 |

## 四、增速陷阱——特别提醒

A 股最常见的问题：**把周期当成长。**

```
真成长：
  海天味业：ROE 30%+、毛利率稳定、现金流 > 1.0
  → 增速来自市场份额扩大或产品升级

假成长（周期股伪装）：
  某养猪公司：某年利润暴增 500% → 不是成长，是猪周期
  某航运公司：某年利润暴增 800% → 不是成长，是运价周期
  → 增速来自行业价格波动，不可持续
```

**快速筛查：**
- 毛利率波动剧烈（某年 40%、某年 10%）→ 可能是周期股
- 利润增速和营收增速严重背离 → 增速来自成本端波动，不是收入增长
- 现金流质量 < 0.5 → 赚的钱可能还没收到

## 五、可持续性快筛

五维评分告诉你「现在好不好」，但不说「好的状态能不能持续」。这需要额外的判断层。

```
增速可持续性快筛（不影响评分，但影响仓位）：

☐ 增速是否来自单一客户/单一需求驱动？
☐ 行业是否处于明显的资本开支周期极端位置？（详见下方周期检测）
☐ 毛利率年升 > 10pp？（暴增可能是短期供需失衡，不是定价权）
☐ 竞争对手是否在疯狂扩产？（预示供给即将过剩）
☐ 下游客户的 Capex 是否在历史极端水平？
☐ **下游客户的 Capex 增速是否在放缓？**（二阶导——详见下方）
☐ 公司市值是否已经兑现了大部分增长？（十倍股问题）

  任一 ☑ → 标记「增速可持续性存疑」
  
  标记的影响：
  → 不改变五星评分（评分是客观数字）
  → Kelly 信号正常生成
  → 但 f* 上限减半（从 20% → 10% NAV）
  → 反映的是：数字好但未来不确定
```

**「可持续性存疑」不是「不好」——是「我们不知道还能好多久」。这是诚实的无知，不是悲观的判断。**

### 周期检测——这条值得单独展开

「行业是否处于资本开支周期极端位置」是企业分析中最重要也最常被忽略的问题。

**操作规则（简化版）：**

> **利润在过去 3 年内出现过腰斩（或亏损）→ 标记为周期股 → PEG 计算时用过去 3 年均值利润替代当前峰值利润。**

**为什么要这么做：**

周期的本质是「当前的利润不代表未来的利润」。PEG 的公式是 PE ÷ 增速。但如果当前利润是周期顶部的利润，那么「增速」和「PE」都建立在不可持续的数字上——PEG 再好看也没有意义。

```
周期股在顶部的典型画像：
  → 利润创历史新高
  → PE 看起来不高（因为 E 特别高）
  → PEG 看起来极低（增速用峰值利润算的）
  → 分析师说「这次不一样」
  → 然后周期反转，利润腰斩，PE 暴涨
  → 「便宜」变成「贵」，中间没有任何信号
```

**案例：兆易创新（603986）**

```
2021 利润：23.4 亿（上一轮周期顶部）
2023 利润： 1.6 亿（腰斩，跌幅 93%）
2026 利润：58.0 亿（年化，新周期顶部？）

→ 3 年内利润从 23.4 → 1.6，腰斩过。周期股确认。
→ 3 年均值利润 ≈ 14 亿
→ 以 3300 亿市值、均值利润 14 亿计算 → PE 236x
→ 即使按当前峰值 58 亿 → PE 57x → 用的是不可持续的峰值利润
→ 估值结论：不要用峰值利润说服自己它便宜。等周期确认后再看。
```

**同期案例对比——真成长 vs 周期：**

| | 兆易创新（存储） | 海天味业（消费） |
|:---|:---|:---|
| 利润波动 | 1.6 → 58 亿（36 倍振幅） | 60 → 75 亿（平稳增长） |
| 3 年内腰斩？ | ✅ 是 | ❌ 否 |
| 利润稳定性 | 周期驱动 | 需求驱动 |
| 峰值 PEG 可信吗？ | 不可信——峰值利润是周期的，不是公司的 | 可信——利润增长来自份额和提价 |
| 估值结论 | 标记周期股，用均值利润 | 正常 PEG |

> **规则不是「不买周期股」——是在周期顶部不假装它是成长股。**

**豁免：首次盈利公司**

```
如果公司在上市以来首次实现全年归母净利润为正：
  → 不适用「3年内腰斩」周期检测
  → 之前的亏损是研发投入和规模爬坡，不是周期底部
  → 利润不是「从高处跌下来的」——是「从不存在到存在的」

判断标准：上市以来首次全年归母净利润 > 0

例：寒武纪（688256）
  2021-2024：连续四年亏损（累计 -34 亿）
  2025：首次全年盈利（+20.6 亿）
  → 豁免周期检测
  → 估值难点不是「周期位置」——是「增速能维持多久」

例：兆易创新（603986）
  一直有盈利，但 2023 年从 23 亿跌到 1.6 亿
  → 不豁免。仍然是周期股。
```

### 二阶导——绝对值不重要，方向才重要

「下游客户的 Capex 是否在历史极端水平」只能告诉你「此刻很高」。「增速是否在放缓」能告诉你「拐点可能在哪」。

```
同样的 $300B Capex：

  情景 A：去年 $200B，今年 $300B（+50%，加速）
    → 市场定价：明年 $450B
    → 所有供应商产能不足 → 量价齐升
    → 利润爆炸增长

  情景 B：去年 $270B，今年 $300B（+11%，减速）
    → 市场定价：明年 $330B
    → 供应商已按 $450B 扩产 → 产能过剩
    → 利润增速骤降，PE 压缩

数字一样。方向相反。结果完全相反。
```

**市场在交易二阶导，不在交易绝对值。**

操作规则：

```
Capex 增速连续两个季度放缓？
  → 标记「需求动能减弱」
  → 供应端已经按更高增速扩产了
  → 供需错配的风险在累积
  → f* 上限减半

不要求精确数据——看趋势就够了。
云厂商的 Capex 指引每个季度都有，不需要模型。
```

**三个层次的二阶导是同一回事：**

| 层次 | 一阶（绝对值） | 二阶（方向） | 市场在交易什么 |
|:---|:---|:---|:---|
| 个股价格 | MA 金叉/死叉 | p 在加速↗还是减速↘ | p 的方向 |
| 行业 Capex | $300B | +50%→+17%→-14% | 增速方向 |
| 公司利润 | 58 亿 | +263%→+50%→负增长 | 增速方向 |

> **一阶导数告诉你「在哪里」，二阶导数告诉你「往哪去」。市场永远在交易后者。**

## 六、框架的边界——模型做不到的事

框架是地图。但地图不是领土。

| 框架能做的 | 框架不能做的 |
|:---|:---|
| 算出 PEG 0.6 | 判断 AI 资本开支还能持续多久 |
| 发现毛利率在上升 | 判断上升是因为定价权还是短期供需 |
| 计算 ROE | 判断管理层是否值得信任 |
| 筛查现金流质量 | 预测技术迭代会不会颠覆这家公司 |
| 给出五星/二星 | 替你做「这个行业我懂不懂」的判断 |

**框架不能替代的四件事：**

```
1. 行业知识
   你知道这个行业怎么赚钱吗？价值链怎么分配？
   中际旭创 = AI 光模块，你需要知道 AI 资本开支持续性。

2. 竞争格局
   谁在和它抢市场？毛利率 46% 能守住多久？
   不是算出来的——是跟踪出来的。

3. 周期判断
   你现在看到的是「结构性增长」还是「周期顶部」？
   框架只能看后视镜——它不知道前面是上坡还是悬崖。

4. 仓位心理
   100 块时你敢重仓吗？1038 块时你敢持有吗？
   数字一样（PEG 0.6），但心理完全不同。
```

> **框架的价值不是替代这些判断——是让你在做了这些判断之后，有一个不依赖情绪的工具来核实你的判断。**

## 七、与 Kelly 框架的接口

估值框架输出：**该标的是否进入 Kelly 扫描池 + 星级 + 可持续性标记**

```
五星标的 + 无可持续性疑虑：
  → 进入 Kelly 扫描池
  → Kelly 信号来了 → 正常 f*（不受限制）

五星标的 + 可持续性存疑：
  → 进入 Kelly 扫描池
  → Kelly 信号来了 → f* 上限减半（≤10% NAV）

四星标的：
  → 进入 Kelly 扫描池
  → Kelly 信号来了 → 正常 f*
  → 但估值不够极致便宜，不做超配

三星标的：
  → 进入 Kelly 扫描池
  → Kelly 信号来了 → f* 上限减半 + 不做长期持有

二星及以下：
  → 不进入 Kelly 扫描池
  → 不管结构多好，不碰
```

## 八、案例：中际旭创（300308）

*数据基于 2026Q1 财报*

| 维度 | 数值 | 评分 |
|:---|:---|:---|
| 增速 | 营收 CAGR +89%，利润 CAGR +123%，Q1 YoY +263% | ⭐⭐⭐⭐⭐ |
| 性价比 | TTM PE 77.8x，PEG 0.6（TTM）/ 0.4（年化） | ⭐⭐⭐⭐⭐ |
| 生意质量 | 毛利率 46%（4年+13pp），净利率 29%（持续上升） | ⭐⭐⭐⭐⭐ |
| 利润真实性 | 待补（毛利率趋势平滑 → 间接可信） | 待定 |
| 财务安全性 | 待补 | 待定 |
| **综合** | 已有三维全满分 | **⭐⭐⭐⭐⭐** |

**增速可持续性快筛：**

| 检查项 | 结果 |
|:---|:---|
| 增速来自单一需求驱动？ | ☑ AI 资本开支 |
| 行业处于 Capex 周期极端位置？ | ⚠️ 大概率不在底部 |
| 毛利率年升 > 10pp？ | ☑ +13pp/1.5年 |

> **标记「增速可持续性存疑」。** 不影响五星评级，但即使 Kelly 出信号，f* 上限减半。

> **十倍股问题：** 从 ~100 到 1038 已经兑现了 10 倍。框架在 100 块时跑出来满分才是真正的价值——现在 1038 跑出来满分是验证，不是机会。框架的最大价值不在 10 倍之后告诉你它便宜，而在 1 倍之前告诉你它值得关注。

## 九、执行节奏

```
每季度财报发布后：
  1. 更新五维评分
  2. 调整标的池（五星→四星→三星，升降级）
  3. 新五星标的进入 Kelly 扫描池
  4. 降为二星的标的从扫描池移除

日常：
  Kelly 框架只在标的池内运行
  不碰池外的标的——不管技术面多诱人
```
