# 反射理论（Reflection Theory）

来源：Michael Chen《投资和股票》+ George Soros《金融炼金术》

## 核心思想

索罗斯的"反射理论"是对传统经济学均衡假设的根本性挑战：

**经典经济学的假设**：市场价格最终反映基本面，供求均衡，价格是客观现实的被动反映。

**反射理论的假设**：市场价格不是对现实的被动反映，而是主动塑造现实的一部分。思想（认知）和现实（行动）之间存在双向反馈——不是单向因果，而是相互影响、彼此扭曲的循环关系。

## 核心机制

```
思想 → 行动 → 结果 → 思想（重新评估）→ ...
```

- **认知功能**：参与者观察市场，形成对价格的判断
- **参与功能**：参与者的行动反过来影响市场价格
- **双向反馈**：认知既反映现实，又受现实影响；现实既被认知所反映，又被参与者的行动所改变

## 市场表现

- 市场总是处于一种**不完美的理解**状态（imperfect understanding）
- 参与者持有的"偏见"会通过行动进入市场本身
- 趋势的形成不是因为基本面，而是因为双向反馈自我强化
- 最终，反馈循环无法维持，趋势反转——这正是"暴风雨式创造性破坏"的表现

## 与历史哲学的联系

Michael Chen将索罗斯的反射理论应用于整个历史进程：

- 历史的参与者（人）对过往历史及自我的重新认识，重新修正行为
-下一刻的历史并不简单重复，而是随参与者认识的修正而重新构成
- 历史具有"路径依赖"和"自反性"——正是这种性质使历史不可精确预测

## 投资含义

- **市场不可有效预测**：因为预测本身会改变结果
- **趋势存在自我强化**：认知和价格互相加强，形成短期相似性
- **顶部/底部不可预测**：无法预知谁是最后一个卖出者/买入者
- **策略选择**：认识到"底部无法预测"，转而以股息率等准绳来锚定买入价值

## 与其他概念的联系

- [[凯利公式]]：理解概率结构是基础，但反射理论说明概率本身是动态的
- [[生存法则]]：理解自己是参与者，而非客观观察者
- [[戴维斯双击与戴维斯双杀]]：市场错误定价（第二类收益）正是反射理论的体现

## 相关人物
- [[乔治·索罗斯]]（George Soros）：反射理论的提出者
- Michael Chen：继承并扩展至历史哲学层面
