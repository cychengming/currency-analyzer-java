# 知识管理工作流

> 来源：LLM Wiki 知识管理系统

## 完整工作流

```
文档导入 → AI 整理 → Wiki 生成 → 双向链接
```

全程不需要手动操作任何图形界面，文件丢进去自动成网。

## 五个步骤

### 第一步：下达指令

用户说「写入知识库」，Hermes 知道需要执行知识库写入操作。

### 第二步：Hermes 自动整理

自动完成：
1. 读取文档内容
2. 提取关键实体（人物、工具、项目）
3. 提取核心概念（方法论、技术原理）
4. 创建结构化的 Markdown 文件
5. 添加 [[双向链接]] 连接相关概念
6. 更新知识库索引和日志

### 第三步：文件结构生成

按 [[LLM-Wiki]] 规范创建文件：
```
knowledge_base/
├── raw/sources/        # 原始文章
├── wiki/entities/      # 实体文件
├── wiki/concepts/      # 概念文件
├── wiki/index.md       # 知识库索引
└── wiki/log.md        # 更新日志
```

### 第四步：Obsidian 展示知识网络

把 wiki 目录作为 Vault 拖入 Obsidian，双链网络自由浏览，Graph View 查看关联强度。

### 第五步：无限循环

每次导入新文档，知识网络自动更新，已有页面补充新信息，矛盾处被标注。

## 工具分工

| 工具 | 角色 |
|---|---|
| [[Hermes-Agent]] | 自动化执行引擎，接收指令，提取知识，创建文件 |
| [[Obsidian]] | 笔记展示层，双向链接和知识网络可视化 |
| [[LLM-Wiki]] | 文件结构规范 |

## 使用规则

| 触发词 | 执行动作 |
|---|---|
| 「写入知识库」 | Hermes 自动整理并写入 |
| 「结合知识库」 | Hermes 检索并整合回答 |
| 普通对话 | 不动知识库 |
