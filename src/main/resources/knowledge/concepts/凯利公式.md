# 凯利公式

凯利公式的核心不是仓位计算，而是对概率 p、风险回报率 R、最大潜在损失 b 这三个底层变量的重新理解。

## 三篇核心解读

- [[概率 p —— 结构创造概率]]：p 不是胜率，而是结构对称度的投影。混沌中不存在概率，p 只在趋势结构中被创造。
- [[风险回报率 R —— 时间几何]]：R 不是收益比，而是上行剩余时间与下行坍塌时间的比值。当未来被提前消费完，R 归零。
- [[最大潜在损失 b —— 生存边界]]：b 不是止损距离，而是结构失效时暴露在坠落维度中的资本比例。b 是生存问题，不是收益问题。

## 三变量关系

```
- p 决定能不能下注（门槛）
- R 决定值不值得下注（效率）
- b 决定能否活下来（生存）
```
