# 克罗的交易系统方法

> 来源：[[斯坦利·克罗]] — 《期货交易策略》《专业商品交易者》

## 概述

克罗的交易系统不是一个机械化的"买/卖信号"系统，而是一套**基于趋势分析的战术框架**。它包括进场时机、加仓策略、持仓管理和平仓纪律四个阶段。核心口诀是：

> **顺着大趋势交易，逆着小趋势进场。**

## 进场策略

### 条件判断

克罗只有在市场同时满足以下条件时才进场交易：

1. **市场展现强烈的趋势特性**，或者分析显示趋势正在酝酿形成
2. **主趋势方向明确**（上涨或下跌）
3. **有合理的战术性进场点**

### 进场时机

在主趋势方向下，克罗选择以下几种技术性进场点：

| 趋势方向 | 进场方式 |
|---------|---------|
| **主趋势上涨** | 技术性回档遇到支撑时买进 |
| **主趋势下跌** | 技术性反弹遇反压时卖出 |
| 盘整后突破 | 显著向某个方向突破时跟进 |
| 显著反转处 | 前一个趋势显著反转之处进场 |

### 50%回调法则

克罗大量使用**45%—55%的回调幅度**作为进场参考：

- 上涨趋势中：回跌到距最近一次上涨点 **45%—55%** 时买进
- 下跌趋势中：反弹到距最近一次下跌底部 **45%—55%** 时卖出
- 时间辅助：开始回调后的 **第三天或第五天**

> 注意：50%法则只是**一般性指南**，用于提示支撑或反压的可能位置，克罗从不将其用作精确预测工具。

## 加仓策略（金字塔加码）

克罗的金字塔加仓法：

1. **初步建仓**：建立初始仓位
2. **确认趋势后加仓**：只有市场走势证明趋势对你有利时才加仓
3. **技术性反转处加仓**：在上述进场点（回调/反弹）处金字塔式增仓
4. **加仓量递减**：每次加仓数量不应超过前一次，形成金字塔结构

### 错误示范（反面教材）

克罗在可可豆案例中描述了常见的**倒金字塔加仓错误**：
- 初始建仓谨慎（少量）
- 价格上涨后不断加码（越加越多）
- 形成"倒金字塔"仓位
- 一次正常回调就导致巨额浮动亏损
- 恐慌中清仓，甚至反手做空——造成双重损失

## 持仓管理

克罗强调：**持有盈利仓位比开仓更难**。

他是杰西·李佛摩的忠实信徒，尤其推崇李佛摩的这句话：

> "我的想法永远不会让我赚钱。我的**坐法**总是让我赚钱。你明白了吗？就是**紧紧地坐着**。"

### 持仓期间的日常工作

克罗每天使用一张[[斯坦利·克罗#克罗的实战分析方法\|市场分析表格]]，记录每个品种：
- 大小趋势方向
- 支撑/阻力位
- 目标价格
- 行动计划

这张表格的作用是**强迫自己客观、冷静、有纪律**，而不是被市场情绪左右。

## 平仓策略

### 何时平仓

| 场景 | 行动 |
|------|------|
| 趋势反转（客观信号确认） | **立即平仓，行动要快** |
| 达到大价格目标 | 考虑逐步减仓 |
| 市场过度狂热/恐慌 | 警惕顶部/底部信号 |
| 仓位让你无法安心睡觉 | 减仓到"睡得着"的水平 |

### 止损设置

克罗的止损哲学：
- **初始止损**：进场时就设定，控制单笔最大亏损
- **移动止损**：趋势有利时持续上移止损点，锁定利润
- **保本止损**：当浮动利润达到保证金的50%时，激活保本止损单
- **纪律**：止损一旦设置，除非市场证明你错了，否则绝不撤销

> "一开始的亏损是最便宜的。"

### 过早平仓的案例

克罗在《专业商品交易者》中多次记录自己**过早平仓**的教训——最典型的是**小麦做空惨败**：他在1.50—2.32的上涨行情中做空，市场涨到2.32时本想回补，却想等再跌2分钱再回补，结果一路涨到2.70才痛苦地回补。

## 实战案例：铜战役（1972—1973）

克罗最经典的战役之一：

| 阶段 | 操作 | 价格区间 |
|------|------|---------|
| 初步建仓 | 从44.00分开始买入250份合约 | 44.00—50.00 |
| 加仓 | 在回调时持续金字塔式加仓 | 50.00—60.00 |
| 最终持有 | 总仓位增大，大部分在60.00以上加仓 | 60.00—72.00 |
| 平仓 | 到达大目标价格70.00—75.00后逐步离场 | 72.00（收盘价71.15） |

**关键教训**：克罗将利弗莫尔的"坐不住"那段话印在卡片上，放在桌上——以此提醒自己不要过早平仓。

## 双重操作方法（顺大势/逆小势）

这是一个关键的战术概念：

| 层级 | 操作方向 |
|------|---------|
| **大趋势** | **顺势操作**（绝不对抗主趋势） |
| **小趋势** | **逆势进场**（在回调/反弹处进出） |

举个例子：如果大趋势是上涨，小趋势在回调：
- **大趋势层面**：做多（顺势）
- **小趋势层面**：在回调到支撑区时做多（逆小势）
- 绝不在大趋势上涨时做空，即使是"小回调"
