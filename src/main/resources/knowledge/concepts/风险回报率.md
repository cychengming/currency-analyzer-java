# 风险回报率

> 来源：投资交易的数学哲学

## 定义

**风险回报率（Risk-Reward Ratio）** = 潜在收益 / 潜在亏损 = a / b

也叫 **R 比率**。

## 在凯利公式中的作用

在[[结构型凯利公式]]中：

$$f* = [p(R + 1) - 1] / (R · b)$$

其中 **R = a/b**（风险回报率）

## 核心逻辑

| 风险回报率 | 含义 |
|---|---|
| R > 1 | 潜在收益大于潜在亏损 |
| R = 1 | 收益等于亏损 |
| R < 1 | 潜在收益小于潜在亏损 |

**只有当 p（胜率）足够高时，低 R 比率的交易才有价值。**

## 交易决策矩阵

| 条件 | 决策 |
|---|---|
| 高胜率 + 高R | 凯利值高，可加重仓 |
| 高胜率 + 低R | 凯利值中等，稳健 |
| 低胜率 + 高R | 需要极高胜率才有价值 |
| 低胜率 + 低R | 放弃 |
