# 股息的作用

来源：Michael Chen《股息的作用》

## 实证数据（鲁B案例）

港币资产投资者，2006/12/31买入1万股鲁B（成本HK$69,900），持有至2009年底：

|  | 股票面值 | 分红累积 | 总值 |
|--|--|--|--|
| 2006年末 | 69,900 | 0 | 69,900 |
| 2007年末 | 38,000 | 3,718 | 41,718 |
| 2008年末 | 49,200 | 8,638 | 57,838 |
| 2009年末 | 129,000 | 13,178 | 142,260 |

- 股价收益：84.55%（面值升值）
- 分红收益：18.85%
- **总收益：103.52%**
- 3年年化股息回报率：**6.28%**（远超同期银行定存利率3.33%）

## 股息的核心作用

**1. 让投资者远离市场价格波动**
- 每年获得高于银行定存的分红，就不必理会市场波动
- 对退休人士、需要现金流的投资者特别重要
- 分红提供独立现金流，无需卖掉股权来支付开支

**2. 熊市中的持股安心剂**
- 相对于买入成本的高股息率，保证可以安心持股
- 林森池1998年买入九仓案例：
  - 买入价HK$11
  - 每股股息HK$0.78
  - 股息率7%，高于美国政府长债（5%）
  - "心中做最坏打算，长线投资"

**3. 资金再配置机制**
- 分红现金可以重新配置，减少短期资金持有量
- 在长期通胀环境下，提高投资效率

## 股息率的实践应用

以股息率为准绳来厘定买入价：
- 股息率 > 长债利率 → 有持有价值
- 市场恐惧时，敢于在低PE高股息率时买入
- 克服"不断看跌"的心理障碍

## 学术争议

- **M-M定理**：在理想市场下，股利政策对公司价值无关紧要
- **戈登公式**：股票价值 = 股利 ÷ (必要收益率 - 增长率)，股利极其重要
- 现实：美国市场股息率从1981年的6%跌至2000年后的接近1%
