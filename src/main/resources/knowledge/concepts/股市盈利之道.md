# 股市盈利之道

来源：Michael Chen《股市盈利之道》及《股市盈利之道及论心理估值及盈利之来源》

## 核心论点

股票市场盈利来自**两部分收益叠加**（戴维斯双击的原理）：

**第一类收益：企业盈利增长**
- 买入合理估值，持有，盈利增长推动股价上涨
- 约15%/年复利（如PE=12，盈利每年增长15%）

**第二类收益：市场错误定价**
- 在市场恐慌时（低PE）买入，在市场狂热时（高PE）卖出
- 这是超额收益的主要来源

## 两种估值陷阱

**戴维斯双击**：盈利↑ + 估值↑ → 惊人复利
**戴维斯双杀**：盈利↓ + 估值↓ → 股价崩盘

## 实践原则

- 市场恐慌时买入（大跌市）：才有便宜货
- 市场狂潮时卖出（大牛市）：才有高价可脱
- 避免在正常估值时买卖——收益主要来自错误定价的修复
