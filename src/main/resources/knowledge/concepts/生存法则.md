# 生存法则

> 来源：投资交易的数学哲学

## 第一性原理

> **生存是第一性原理。**

只有活着，才能看到下一天，开启新的战斗。增长，是生存的奖励。

## 亏损的非对称性

[[复利]]最害怕的不是回报不够高，而是出现重大损失：

| 亏损幅度 | 回本需要的盈利 |
| ---- | ------- |
| -50% | +100%   |
| -80% | +400%   |
| -90% | +900%   |

**一次毁灭性的亏损，需要多次成功才能弥补。**

## 核心法则

> **不是赚得最多，而是亏得最少。**

这是所有真正懂得复利的投资者都本能遵循的关键法则。

## 生存检查清单

1. **永不 ALL IN** — 即使信心极高，也不全押
2. **使用凯利上限** — 半凯利或四分之一凯利
3. **优先止损** — 先考虑能承受多少亏损
4. **追求正向期望** — 不是每次都对，而是长期数学期望为正
