# 风险回报率 R —— 时间几何

*《重回凯利公式：风险回报率篇》核心提炼*

## 核心观点

R 不是"能赚多少 / 可能亏多少"的价格比例，而是**未来状态空间向两个方向展开的几何不对称**。

## R 的严格定义

```
R = 上行剩余时间 ÷ 下行坍塌时间
```

- 上涨是**缓慢积累**的时间过程（需要新资金、叙事、信用持续进入）
- 下跌是**压缩释放**的瞬时崩塌（只需要一个触发点）

## 为什么趋势末端 R 归零？

趋势末期：
- 边际买家枯竭
- 信用扩张接近极限
- 叙事被完全透支
- 所有人已经进场

**未来被提前消费完了。** 上行不再拥有"时间长度"，R 自动归零甚至转负。

## 奇点区的特殊情况

奇点附近 R 看起来极大，但 p 不存在——系统从"吸引场"退回"扩散场"，价格剧烈波动但无方向结构。

## R 的真正角色

| R 的状态 | 含义 |
|---------|------|
| R > 0 | 未来仍在展开，有不对称空间 |
| R = 0 | 未来被消费完，结构无剩余 |
| R < 0 | 系统进入坍塌通道 |

## 关键判断

> 即使胜率 100%，如果未来不对称已经消失，仍然是不值得下注的结构。

## 三变量联立

只满足单一条件是不够的：

- **高 p + 低 R = 幻觉**
- **高 R + 无 p = 混沌**
- 只有 **p 可定义 + R 明显为正**，系统才处于正向时间几何中
