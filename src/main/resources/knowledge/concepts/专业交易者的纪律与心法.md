# 专业交易者的纪律与心法

> 来源：[[斯坦利·克罗]] — 《期货交易策略》《专业商品交易者》

## 克罗的第一信条：纪律、纪律、纪律

克罗在《期货交易策略》中写道：

> "成功操作最重要的三个特质是：**纪律、纪律、纪律。**"

这不是简单的重复——他亲身经历过每一次偏离"教条"都必然赔钱的痛苦验证。他说：

> "每当我漫不经心或蠢到竟然偏离这些'教条'时，我一定赔钱——这没什么好惊讶的。"

## 自律 vs 冲动：赢家与输家的区别

克罗认为，赢家和输家在技术层面上的差异并不大，真正的差别在于：

> **赢家总是心无旁骛地坚守基本策略，而输家总是心无旁骛地一再避开和违背这些守则。**

### 输家的典型行为模式

| 行为 | 原因 | 结果 |
|------|------|------|
| 根据情绪而非纪律行事 | 冲动、贪婪、恐惧 | 追涨杀跌 |
| 依据感觉而非逻辑 | 主观臆断替代客观分析 | 逆势操作 |
| 以主观而非客观 | 选择性接受信息 | 忽视趋势反转信号 |
| 让输的恐惧战胜赢的希望 | 拿不住盈利仓位 | 赚小钱输大钱 |
| 急于证明自己比系统聪明 | 过度自信 | 无视系统信号 |

### 赢家的行为特征

克罗在序言中总结：成功的交易者必须具备——

1. **超越欲望和一厢情愿的想法**
2. **实际而且客观**
3. **踏实而且守纪律**
4. **对自己的分析和策略满怀信心**
5. **忍受无聊和惰性**（不贸然行动）

## "紧紧坐着"——李佛摩的启示

克罗在《专业商品交易者》中反复引用杰西·李佛摩（Jesse Livermore）。他有一个非常著名的习惯：

> 他把李佛摩的这段话打印在小卡片上，放在办公桌前：

> "……在华尔街度过了很多年，赚了几百万，又亏了几百万以后，我想告诉你：**我的想法永远不会让我赚钱。我的坐法总是让我赚钱。你明白了吗？就是紧紧地坐着。**"

这段话对克罗的影响如此之深，以至于他每天早上都阅读《股票作手回忆录》，尤其是"坐不住"的那一段。他整天带着这本书，交易时把它放在电话前面。

> **判断对错不是本事，坐得住才是。**

## 克罗的交易心理作业

克罗每天都做以下心理功课：

### 1. 自我对话

他每天收盘后询问自己：
- 今天的操作是否基于客观分析？
- 是否因为恐惧或贪婪改变了原有计划？
- 仓位是否仍然符合大趋势方向？
- 止损单是否设置到位？

### 2. 隔离噪音

克罗有一项铁律：**绝不让外部信息和他人意见干扰自己的判断。**
- 不听从营业员的"忠告"
- 不理睬市场小道消息
- 不参考别人的意见
- 更重要的是：**不把自己的意见告诉别人**

> 他的理论是：一旦你把意见告诉别人，你就会不自觉地维护它——这会让你忽视趋势反转的证据。

### 3. 在狂热中保持冷静

克罗在《专业商品交易者》中描述了一个场景：市场连续涨停/跌停，所有人都在疯狂交易，办公室的电话响个不停。他的应对是：

> "在这样的市场中，你必须非常冷静，有耐心，让市场朝你的方向走。如果你主观行动，有情绪化，你的交易肯定不理性。市场波动越大，振幅越大，你越要保持冷静和放松。"

## 忍：交易中最被低估的美德

克罗反复强调一个很多交易者无法接受的事实：**大部分时间，最好的操作是不操作。**

### 等待的三种形式

| 形式 | 内容 |
|------|------|
| **等待趋势形成** | 市场没有趋势时不交易 |
| **等待最佳进场点** | 在45%—55%回调处入场 |
| **等待持仓展开** | 建仓后耐心持有，不要频繁操作 |

### 不只是"做"，更要"不做"

克罗的客户经常做的一件事就是——要求他做些什么。交易者的焦虑心理让他们总想"操作"，即使是错的。克罗的哲学是：

> 当市场没有给出明确信号时，当你的分析显示趋势不确定时，**什么都不做就是最好的策略。**

## 克罗的个人纪律检查表

从两本书中总结的克罗纪律清单：

- [ ] 交易前是否做了完整的市场分析？（大小趋势、支撑阻力、目标）
- [ ] 仓位是否在资金承受范围之内？
- [ ] 是否设定了止损单？
- [ ] 是否严格按照信号/计划操作，而不是凭冲动？
- [ ] 盈利仓位是否设置了保护性止损？
- [ ] 是否忍住了不提前平仓盈利仓位？
- [ ] 是否忍住了不在亏损仓位中加码？
- [ ] 是否保持客观，不被市场情绪影响？
- [ ] 是否准备好接受错过行情的代价？
