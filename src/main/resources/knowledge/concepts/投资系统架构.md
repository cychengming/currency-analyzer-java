## 二、Kelly 战术层框架

> **L2 策略规格**: [[Kelly QDII 策略规格]] — 精确规则、参数、入场/出场条件

### 2.1 三条件筛选

```
条件              含义                         阈值
─────────────────────────────────────────────────────
p（趋势）     MA20 > MA50 → 趋势已确立         ✅/❌
R（风险）     1年位置 < 35% → 在低位          数值<35
b（赔率）     60日年化波动率 < 30% → 可控      数值<30
─────────────────────────────────────────────────────
信号判定：三个条件同时满足 → Kelly信号
```

### 2.2 f* 仓位计算

```
上行空间 = (1年高点 - 当前) / 当前
下行风险 = (当前 - 1年低点) / 当前
赔率比 b = 上行空间 / 下行风险

f* = min(b × 简化系数, 20%)    // 上限20% NAV
首次建仓 ≤ 15% NAV
```

### 2.3 数据源优先级

```
场内ETF > 场外NAV > 香港互认基金 > 指数代理（跳过）
```

## 三、补丁层（2026-05-22 追加）

### 补丁1：趋势健康过滤器

Kelly 数学通过后，追加一票否决检查：

```
检查项                    通过条件
─────────────────────────────────────────────────────
3年年化收益率            > 通胀率（≈2.5%）
vs 对标指数             不长期跑输
价格行为类型             周期性回调（非结构性衰退）
创新高频次               正常或偏多
─────────────────────────────────────────────────────
结构性衰退 → ❌ 跳过（如标普消费品118002）
周期性回调 → ✅ 进入Kelly开仓流程
```

**判断要点：**
- **结构性衰退**：3年年化跑输通胀、价格长期阴跌、反弹无力 → 低位的低不是机会
- **周期性回调**：长期趋势向上、短期回到低位、基本面逻辑没变 → 标准的Kelly入场

### 补丁2：宏观/资金流交叉验证

Kelly 信号应和以下数据交叉验证（依赖 Ashare MCP）：

| 数据维度 | 工具 | 验证逻辑 |
|:--------|:----|:---------|
| 行业资金流向 | `board_flow` | 板块在净流出→信号降级 |
| 板块强度排名 | `board_industry` | 板块排名在下降→信号降级 |
| 北向资金流向 | `hsgt_flow` | 外资流出→A股信号谨慎 |
| 概念板块排名 | `board_concept` | 热点不在该方向→信号降级 |

**规则：** MCP 提供的实时数据覆盖三个维度以上**看空**时，Kelly 信号从"执行"降级为"观察"。

### 补丁3：持仓相关性管理

Kelly 开新仓前检查与现有持仓的相关性：

```
相关性检查：
  ┌─ 待开仓标的
  ├─ vs 现有持仓
  │
  ├─ 高相关 (>0.7) → 总敞口 ≤ max(现有+f*, 25%NAV)
  ├─ 中相关 (0.3-0.7) → 正常 f*
  └─ 低相关 (<0.3) → 正常 f* + 分散化加分

当前持仓相关性（估算）：
  164824 印度 ──── 006105 印度 ──── 高度相关
  016055 纳指 ──── 独立
  020516 东南亚 ──── 与印度中低相关
```

简化版本（暂不建表）：**同一市场/指数的持仓合计不超过 30% NAV**。

## 四、执行流程（完整版）

```
每周全市场扫描
    │
    ▼
Kelly 三条件筛选
    │
    ▼
补丁1：趋势健康检查
   ├─ 结构性衰退 → ❌ 跳过
   └─ 周期性回调 → 继续
        │
        ▼
补丁2：资金流交叉验证
   ├─ 多维度看空 → 降级为观察
   └─ 中性或偏多 → 继续
        │
        ▼
补丁3：相关性检查
   ├─ 与现有持仓高相关 → 限制总敞口
   └─ 低相关 → 正常f*
        │
        ▼
输出 Kelly 信号
   ├─ 持仓标的 → 定时调整
   └─ 新候选 → 开仓流程
        │
        ▼
执行 → 写入 trade-log.md
     → 写入 Obsidian journal/
     → Feishu 推送
```

## 五、已知局限性（写在系统里）

| 局限       | 说明                           | 应对            |
| :------- | :--------------------------- | :------------ |
| 错过趋势性资产  | AI浪潮、NASDQ长期上涨 → Kelly在高位说别买 | 战术层不管，战略层定投覆盖 |
| 误判价值陷阱   | 结构性衰退资产位置低→假信号               | 补丁1过滤         |
| 滞后于基本面变化 | 只用量价数据，不看财报/新闻               | 补丁2资金流部分弥补    |
| 单市场失效    | 长期单边市场（如日本失去的三十年）            | 多市场覆盖+定投底仓    |
