# 乔治·索罗斯

> 来源：[[投资交易的数学哲学]]

## 基本信息

- **全名**：乔治·索罗斯（George Soros）
- **称号**："金融大鳄"、趋势之王
- **投资风格**：宏观对冲、趋势博弈、结构性拐点押注

## 凯利结构

| 变量 | 特征 |
|---|---|
| 胜率 p | 中等（约30%） |
| 风险回报率 R | 很高（5倍甚至更高） |
| 最大亏损 b | 很小（投资组合最高20%） |

**结构类型**：[[索罗斯的趋势爆发型复利]]

## 核心策略

- **等待结构性拐点**，然后重仓下注
- **用严格止损**锁住亏损
- **试探性押注**潜在大趋势
- **用趋势爆发**获得风险回报率

## 经典案例：做空英镑

- 最多亏损约 **3%**
- 潜在收益超过 **10%**
- 风险回报比 R = 3.3 以上
- 即使胜率只有30%，凯利公式也会给出合理甚至极高的下注比例

## 核心名言

> "关键不是你对还是错，而是你对的时候赚多少，错的时候亏多少。"

这正是结构型凯利思想的核心："风险回报率及最大损失"。

## 投资哲学

他的下注方式类似于期权交易者：
- 用**小损失**换极大利润
- 靠**大趋势**获得风险回报率保证

这种结构，在凯利公式中，虽然胜率低，但结构强，依然是**正凯利结构**。
