# 斯坦利·克罗

> 来源：知识库

## 基本信息

- **英文名**：Stanley Kroll
- **身份**：期货交易大师、投资作家
- **国籍**：美国
- **活跃年代**：1960s—1990s
- **代表著作**：《期货交易策略》、《专业商品交易者》、《克罗谈投资》

## 人物简介

斯坦利·克罗是期货交易史上最具影响力的实战派大师之一。他既不是学院派理论家，也不是纯粹的短线投机者——而是一个**长期顺势的趋势跟踪交易者**，在1960s—1970s的全球商品期货市场中创造了惊人的战绩。

他最著名的战绩是 **18,000 美元起步，三年内增值到 1,000,000 美元**（1970—1973年），同时为合伙人赚取了同样规模的利润。他在铜、白银、白金、可可豆等市场中的大规模战役，至今仍是趋势交易领域的经典案例。

## 核心哲学

克罗的交易哲学可以用一句话概括：

> **辨别市场重大持续走势，并且顺势操作。**

他的思想与[[投资交易的数学哲学]]中的凯利体系有很强的互补性——凯利公式回答的是"仓位该多大"，克罗回答的是"什么时候该持仓、什么时候该不动"。

### 五个核心原则

| #   | 原则             | 简要说明                           |
| --- | -------------- | ------------------------------ |
| 1   | **趋势是你的朋友**    | 永远顺着主要趋势方向交易                   |
| 2   | **KISS（务求简单）** | Keep It Simple, Stupid — 不要搞复杂 |
| 3   | **纪律、纪律、纪律**   | 最重要的三个投机特质                     |
| 4   | **让利润奔跑，截断亏损** | 赚钱的仓位要拿住，赔钱的要快跑                |
| 5   | **"紧紧坐着"**     | 李佛摩的教诲：判断正确不算本事，坐得住才是          |

## 代表作中的关键贡献

### 《期货交易策略》

本书系统性地阐述了趋势跟踪交易的**策略层**（做什么）和**战术层**（怎么做）：
- 第一篇：交易策略和战术（什么是策略、技术系统只是一半、KISS原则、赢家与输家）
- 第二篇：价格趋势分析与研判（操作工具、基本面vs技术面、长期趋势识别）
- 第三篇：操作时机（纪律、市场消化消息、交易系统、双重操作方法、季节性波动、仓位管理原则）
- 第四篇：实战（李佛摩的启示、市场无好坏、止损控制、捕捉大行情）

### 《专业商品交易者》

本书以**第一人称实战记录**的形式，完整还原克罗在大宗商品市场中的真实交易：
- **铜战役**：250份合约建仓，价格从44.00分涨到72.00分以上，实现百万级利润
- **铂金战役**：300份合约，从143.00到190.00+
- **白银战役**：最多持有310份合约，经历100万浮动利润蒸发又收回的过山车行情
- **小麦惨败**：做空后市场大涨，被迫高价回补

## 克罗的实战分析方法

克罗每天使用一张 **市场分析表格**，对每个持仓品种填写：
1. **大趋势**（上涨/下跌/盘整）
2. **小趋势**（同上）
3. **大支撑/大阻力**
4. **小支撑/小阻力**
5. **振荡区间或趋势通道**
6. **目标价格**（大目标+小目标）
7. **评论与行动**

这个表格强迫他**客观、理性、有纪律**地确认每个市场的关键技术因素，而不是凭感觉交易。
