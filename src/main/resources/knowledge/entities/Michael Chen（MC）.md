# Michael Chen（MC）

中文投资博主，博客：michael-chen.blog.caixin.cn

## 背景

- 2007-2009年中国股市暴涨暴跌的亲历者
- 投资风格：集中持股、长期持有、重视股息率
- 方法论继承：林森池（香港）、巴菲特（美国）、索罗斯（哲学）

## 核心投资思想

1. **投资连续性**：投资是连续过程，不以年度划分
2. **持股心法**：买入时仔细盘算，持有时安坐如山
3. **股息率为锚**：以股息率厘定买入价，熊市安心持股
4. **双击收益**：企业盈利增长 + 市场估值修复
5. **反射理论**：继承索罗斯，将认识论应用于投资
