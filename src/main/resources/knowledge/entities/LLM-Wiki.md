# LLM Wiki

> 来源：LLM Wiki 知识管理系统

## 基本信息

- **类型**：知识库文件结构规范（不是独立应用）
- **作者**：nashsu
- **仓库**：https://github.com/nashsu/llm_wiki

## 核心思路

让 AI 增量构建一个持久化的 Wiki。

传统笔记软件的问题：
- 写了几十篇笔记，但笔记之间是孤立的
- 不知道「苹果」这个词在其他所有地方出现过
- 每次问 AI 都是从零开始搜索，临时拼凑答案

LLM Wiki 的解决思路：
1. 导入文档不会只是索引一下就完事
2. 系统会**真正理解**文档，提取关键实体、概念、关系
3. 生成或更新对应的 Wiki 页面，保存在本地
4. 页面之间形成引用和关联
5. 下次提问时，Wiki 里已有结构化知识，直接基于 Wiki 回答

## 文件结构

```
knowledge_base/
├── raw/sources/        # 原始素材
├── wiki/entities/      # 实体（人物、工具、项目）
├── wiki/concepts/      # 概念（方法论、原理）
├── wiki/index.md      # 知识库索引
└── wiki/log.md         # 更新日志
```

## 核心特点

| 特点 | 说明 |
|---|---|
| 完全自动化 | 不需要手动整理笔记，AI 自动完成 |
| 本地存储 | 数据永远属于自己，不上传到服务器 |
| 持久化积累 | 知识不断积累，不是每次从零开始 |
| 只需提问 | 只需要提问和探索，其他交给 AI |
