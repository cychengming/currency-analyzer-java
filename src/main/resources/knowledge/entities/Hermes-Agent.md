# Hermes Agent

> 来源：LLM Wiki 知识管理系统

## 基本信息

- **类型**：自主 AI 代理（Automated AI Agent）
- **开发商**：Nous Research
- **功能**：自动化执行引擎 + 知识库管理

## 核心能力

- 内置 LLM Wiki Skill（内置），可按 LLM Wiki 规范操作知识库
- 内置学习循环，能从经验中创建和改进技能
- 支持 macOS、Linux、Windows

## 在知识管理系统中的角色

```
文档导入 → Hermes Agent 自动整理 → Wiki 生成 → 双向链接
```

Hermes 承担的功能：**自动化执行引擎**

接收到「写入知识库」指令后，自动完成：
1. 读取文档内容
2. 提取关键实体（人物、工具、项目）
3. 提取核心概念（方法论、技术原理）
4. 创建结构化的 Markdown 文件
5. 添加 [[双向链接]] 连接相关概念
6. 更新知识库索引和日志

## 使用规则

| 触发词 | 行为 |
|---|---|
| 「写入知识库」 | 执行导入操作 |
| 「结合知识库」 | 检索知识库 |
| 普通对话 | 不动知识库 |
