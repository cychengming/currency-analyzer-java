# 林森池（Lin Senchi）

香港知名投资专家，著有《证券分析实践》（简体版《投资王道》）

## 核心投资方法

林森池是Michael Chen（MC）投资方法论的核心来源，其投资方法强调：

**1. 以素质降低风险，而非以分散投资降低风险**
- 深入理解企业本身
- 不依赖组合分散来管理风险

**2. 在零风险之下重锤出击**
- 做好功课
- 在有安全边际时大举买入

**3. 股息率为锚**
- 股息率 > 长债利率 → 有持有价值
- "心中做最坏打算，长线投资"
- 1998年买入九仓：买入价HK$11，股息率7%（高于美国长债5%）

**4. 着眼企业股权数目和现金流**
- 所投资公司盈利业绩是否不断增长
- 分红是否逐年继续增加
- 公司经营之道是否合适稳健

## 代表案例

- 1998年恒指跌穿11,000点时，买入九仓（Wharf Holdings）
  - 当时满手现金，几乎全部投入
  - 平均成本HK$11
  - 每股派息HK$0.78，股息率7%
- 九仓业务未老化，但高股息率才是持股安心的根本原因
