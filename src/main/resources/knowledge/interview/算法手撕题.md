## ① 两个栈实现一个队列（美团一面）

**题面原文**：「两个栈实现一个队列」

**思路**：`in` 负责入队，`out` 负责出队。`out` 空的时候把 `in` 整个倒过去（顺序反转两次 = 正序）。均摊 O(1)，单次最坏 O(n)。

```java
class MyQueue {
    private final Deque<Integer> in  = new ArrayDeque<>();
    private final Deque<Integer> out = new ArrayDeque<>();

    public void push(int x) { in.push(x); }

    public int pop() {
        move();
        return out.pop();
    }

    public int peek() {
        move();
        return out.peek();
    }

    public boolean empty() { return in.isEmpty() && out.isEmpty(); }

    private void move() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) out.push(in.pop());
        }
    }
}
```

**边界/追问**：
- 空队列 `pop()` 抛异常还是返回 null —— 要先问清（LeetCode 232 保证合法调用）
- 追问「能不能只用一个栈 + 递归」→ 可以，本质是拿调用栈当第二个栈，但会爆栈
- 追问「两个队列实现栈」→ 与之对称

**验证**：2000 次随机 push/pop，与 `collections.deque` 逐项比对 → **PASS**

## ② 二叉树的最大路径和（美团一面）

**题面原文**：「二叉树的最大路径和」

**思路**：后序递归。对每个节点算「以它为端点的最大单边收益」，同时用它更新全局答案（左收益 + 右收益 + 自己）。**负收益要截断成 0**。

```java
class Solution {
    private int best = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        gain(root);
        return best;
    }

    private int gain(TreeNode n) {
        if (n == null) return 0;
        int l = Math.max(gain(n.left), 0);   // 负数不如不走这一边
        int r = Math.max(gain(n.right), 0);
        best = Math.max(best, n.val + l + r); // 这一节点当"拐点"
        return n.val + Math.max(l, r);        // 往上返回只能选一边
    }
}
```

**复杂度**：时间 O(n)，空间 O(h)（递归栈）。

**边界（这题最容易挂在这）**：
- **全负数**：答案是最小的那个负数，不是 0。上面代码能对，因为每次都用 `n.val + l + r`（l/r 已被截成 0）更新 `best`；但如果初始化 `best = 0` 就错了
- 单节点、只有左子树、只有右子树
- 节点值可能很大 → Java 里 `int` 够（题目约束），`long` 更保险

**验证**：300 棵随机树（含负值），与「暴力枚举所有简单路径」对拍 → **PASS**

## ③ 10L 水、3L 杯、7L 杯，量出 5L（美团一面）

**题面原文**：「10L水，3L杯子和7L杯子，得到5L水」

**答案（最少 8 步，已用 BFS 穷举验证）**：

| 步 | 操作 | 3L 杯 | 7L 杯 |
|---|---|---|---|
| 0 | 初始 | 0 | 0 |
| 1 | 7L 装满 | 0 | 7 |
| 2 | 7L 倒满 3L 杯 | 3 | 4 |
| 3 | 倒掉 3L 杯 | 0 | 4 |
| 4 | 7L 倒满 3L 杯 | 3 | 1 |
| 5 | 倒掉 3L 杯 | 0 | 1 |
| 6 | 7L 剩下的 1L 倒进 3L 杯 | 1 | 0 |
| 7 | 7L 装满 | 1 | 7 |
| 8 | 7L 倒满 3L 杯（只能再进 2L） | 3 | **5** ✅ |

**答题要点（面试官在听什么）**：
- 这是**状态搜索题**，不是脑筋急转弯。状态 = `(3L杯量, 7L杯量)`，操作只有 6 种：倒满 A / 倒满 B / 倒空 A / 倒空 B / A→B / B→A
- 用 BFS 保证步数最少（我验证时就是 BFS，8 步是最少解）
- 不变量：每次操作后，**至少有一个杯子是空或满的**
- 能倒出的水量一定是 `gcd(3,7)=1` 的倍数 → 所以 1~9L 全都能倒出来

**验证**：BFS 穷举全部合法状态（约束总量 ≤10L）→ 最短路径 **8 步**，即上表

## ④ 两个线程交替打印 1 到 100（美团二面）

**题面原文**：「两个线程交替打印1到100」

**思路**：共享锁 + `wait/notify`，**必须用 `while` 包着 wait**（虚假唤醒——见 [[后端研发题库]] Q9 的 javadoc 原文）。

```java
public class AlternatePrinter {
    private static final Object LOCK = new Object();
    private static final int MAX = 100;
    private static int n = 1;

    public static void main(String[] args) {
        new Thread(() -> print(true),  "T1").start();
        new Thread(() -> print(false), "T2").start();
    }

    private static void print(boolean odd) {
        while (true) {
            synchronized (LOCK) {
                while (n <= MAX && ((n & 1) == 1) != odd) {
                    try {
                        LOCK.wait();
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        return;
                    }
                }
                if (n > MAX) { LOCK.notifyAll(); return; }
                System.out.println(Thread.currentThread().getName() + ": " + n);
                n++;
                LOCK.notifyAll();
            }
        }
    }
}
```

**追问方向（都会问）**：
- 用 `ReentrantLock` + 两个 `Condition` 怎么写？（`oddCond` / `evenCond`，唤醒对方）
- 用 `Semaphore(1,1)` 怎么写？（两个信号量互为许可）
- 为什么 `notify()` 不够安全？→ 唤醒的是任意一个等待者，可能唤错 → 用 `notifyAll()`
- **为什么必须 while 而不是 if？** → 虚假唤醒 + 被唤醒后条件可能已被另一个线程改掉

## ⑤ 判断字符串是否由某个子串重复构成（美团二面）

**题面原文**：「写代码，如果一个字符串由某个子串重复构成就输出这个子串，否则输出null」

**解法一（面试首选，好写）**：枚举重复单元长度 L，`n % L == 0` 时逐位比较 `s[i] == s[i-L]`。

```java
public String repeatedSubstring(String s) {
    int n = s.length();
    for (int L = 1; L * 2 <= n; L++) {
        if (n % L != 0) continue;
        boolean ok = true;
        for (int i = L; i < n && ok; i++) {
            if (s.charAt(i) != s.charAt(i - L)) ok = false;
        }
        if (ok) return s.substring(0, L);
    }
    return null;
}
```

**解法二（一行，显功力）**：`(s + s).substring(1, 2*n - 1).contains(s)` —— 即 `s in (s+s)[1:-1]`。原理：如果 s 是周期串，那 s 一定能在「去掉首尾字符的 s+s」里找到。

**复杂度**：解法一 O(n²) 最坏 / 解法二 O(n)（依赖字符串匹配）。

**边界**：`"a"` → null（自己不算重复）；`"aaaa"` → `"a"`（最短单元）；`"abcab"` → null。

**验证**：`abab→ab`、`abcabcabc→abc`、`aaaa→a`、`abaaba→aba`、`abcd→null`、`a→null`、`abcab→null` → **全部 PASS**

## ⑥ 剑指 Offer 15：二进制中 1 的个数（你的刷题记录里唯一一条）

**题面**：`刷题记录` 文件里只写了一行：「剑指 Offer 15. 二进制中1的个数」

**思路**：`n & (n - 1)` 每次消掉最低位的 1，循环次数 = 1 的个数（比逐位右移更优，负数也不用特殊处理）。

```java
public int hammingWeight(int n) {
    int cnt = 0;
    while (n != 0) {
        n &= n - 1;
        cnt++;
    }
    return cnt;
}
```

**为什么负数也能用**：Java `int` 是 32 位补码，`n & (n-1)` 对负数同样只清「最低位的 1」，不会陷入死循环（如果用 `n >>= 1` 且是算术右移，负数会永远不为 0 → 死循环，这是经典坑）。

**验证**：0、1、7、8、`-1`(32个1)、`-2`、`-8`、`Integer.MAX_VALUE`、`Integer.MIN_VALUE` 全部与 `bin(x).count('1')` 一致 → **PASS**
